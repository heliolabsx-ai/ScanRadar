# Patterns (double/triple bottoms and tops) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Detect double and triple bottoms and tops on 5-minute bars for every stock, show them as forming / triggered / failed on a new Patterns tab with levels, score and the pattern drawn on the chart, grade every trigger, alert BUY/SELL on Telegram and the Mac, and ship with hit rates computed over the 42 stored days.

**Architecture:** A pure detector in `core/patterns.py` emits per-day pattern lifecycles tagged with the minute each fact became knowable; `as_of(at)` filters them, so replay, today's view and the live loop all see identical rows. Rows persist in a `patterns` table (replay rows from the backtest CLI and `_prepare_day`, live rows from a 60-second loop in the API process with its own process pool). The dashboard gains a Patterns tab that reuses the header, slider, chart and notification code.

**Tech Stack:** Python 3.12, pandas/numpy, FastAPI, psycopg 3, TimescaleDB, Redis, vanilla JS + canvas. Tests: pytest, node:test.

**Spec:** `docs/superpowers/specs/2026-10-18-patterns-design.md`

## Global Constraints

- One as-of definition: a pattern fact is tagged with the close minute of the 5m bar that made it knowable (`bar.ts + 5 min`); `as_of(at)` shows only facts with minute `≤ at`. Nothing in a stored row is derived from later bars.
- Rows are never mutated after creation except `superseded_at`, `outcome`, `checks`/`score` at the trigger, and `failed_at`.
- Defaults: `TOL=0.004`, `MIN_SEP=4`, `MAX_SEP=36`, `MIN_RETRACE=0.0035`, `K=2`, `FAIL_BARS=3`. Changing them changes `detector_hash`.
- Pairing: a newly confirmed swing pairs with the most recent earlier qualifying swing only; a third matching swing creates a triple row and sets `superseded_at` on the double.
- OI check: OI at the second point lower than at the first, for bottoms and tops alike.
- The engine and ingest live path are untouched. Telegram for pattern triggers goes through `core/notify.py` from the API process; one message per (symbol, kind) per day.
- `detect_day` for 213 symbol-days must run under 2 s on the VPS (measure; the budget in the unit test is 0.3 s for 30 synthetic symbol-days on the Mac).
- No new runtime dependency except `requests` in the api image (for Telegram).
- Scanner tab behaviour unchanged. No images contain `.env`.

## Review Focus

1. A symbol-day with missing 5m bars (illiquid or gap): index arithmetic must use bar positions, and `MIN_SEP/MAX_SEP` count bars, not minutes → `test_detect_with_gaps_uses_bar_positions` in Task 1.
2. A pattern whose second low confirms in the last bars of the day never triggers; it must still appear as forming until the close and be stored → `test_forming_at_close_is_kept` in Task 1.
3. `as_of(at)` before `formed_at` hides the row; between trigger and fail it shows triggered; after fail shows failed → `test_as_of_state_transitions` in Task 1.
4. OI missing or zero at either point → OI check false, score ≤ 4, no exception → `test_score_without_oi` in Task 1.
5. `/api/patterns` for today at 09:16 (no complete 5m bar yet) → 200 with empty rows, not 500 → `test_today_rows_empty_before_first_bar` in Task 5.

### Task 1: `core/patterns.py` detector and as-of view

**Files:**
- Create: `core/patterns.py`, `tests/test_patterns.py`

**Interfaces:**
- Consumes: `core.rules.resample(df1m, "5m")` for complete bars (`df1m` is cut to complete minutes before resampling in `bars5m`).
- Produces:
  - `DEFAULTS: dict`, `detector_hash(params: dict = DEFAULTS) -> str` (sha256 of version string + sorted params, first 12 hex).
  - `bars5m(df1m: pd.DataFrame) -> pd.DataFrame` — complete 5m bars only (a bar is complete when its 5 minutes are all `< last_ts + 1min`), columns `ts, open, high, low, close, volume, oi, vwap, close_at` (`close_at = ts + 5min`), plus running `avg_vol` (mean 5m volume so far) and `day_pct` (close / prev_close − 1 needs `prev_close`, passed in).
  - `swings(b: pd.DataFrame, k: int) -> list[tuple[int, str, int]]` — `(bar_index, "low"|"high", confirmed_at_index)` in confirmation order.
  - `detect_day(df1m: pd.DataFrame, prev_close: float, params: dict = DEFAULTS) -> list[dict]` — each dict: `kind` (`double_bottom|triple_bottom|double_top|triple_top`), `side` (`long|short`), `points` (list of `{ts, price, oi, idx}`), `neckline`, `formed_at`, `triggered_at|None`, `entry|None`, `stop`, `target`, `failed_at|None`, `abandoned_at|None`, `superseded_at|None`, `facts` (`{day_pct_at_p2, oi_p1, oi_p2, vol_ratio_p2, vol_ratio_trigger|None, close_vs_vwap_trigger|None, last_close_vs_vwap_at: {minute: bool}}` is too much; instead store `vol_ratio_p2`, `vol_ratio_trigger`, `vwap_ok_trigger`, `day_pct_p2`, and `as_of` reads VWAP side for forming rows from the bars it is given).
  - `as_of(patterns: list[dict], at: pd.Timestamp, ctx: dict) -> list[dict]` — `ctx = {"sector_pct": float|None, "bars": bars5m frame}`; returns rows visible at `at` with `state` (`forming|triggered|failed`), `age_min`, `checks` (six booleans in spec order: extended, oi, volume, sector, vwap, confirming_close), `score` (count of the first five), `rr`.
  - Timestamps are tz-aware IST `pd.Timestamp`.

def test_double_bottom_detected_with_levels():
    d, pc = shaped_day(bottom_shape(), oi=[...falling between lows...])
    pats = detect_day(d, pc)
    p = [x for x in pats if x["kind"] == "double_bottom"][0]
    assert p["side"] == "long" and abs(p["points"][0]["price"] - p["points"][1]["price"]) / p["points"][0]["price"] <= 0.004
    assert p["neckline"] == max(high between the two lows) and p["stop"] == min(point prices)
    assert p["target"] == pytest.approx(p["neckline"] + (p["neckline"] - p["stop"]))
    assert p["triggered_at"] == close_at of the first bar closing above the neckline after formed_at
    assert p["entry"] == that bar's close

def test_lower_low_is_not_a_double_bottom(): second low 1% below the first → no double_bottom
def test_triple_extends_and_supersedes(): three lows → one triple row, the double has superseded_at == triple formed_at, no (L2,L3) double
def test_top_mirrors(): double_top with side short, neckline = lowest low between, stop = max high, target below
def test_failed_within_3_bars(): trigger then close back below neckline within 3 bars → failed_at set; a close back after 4 bars → failed_at None
def test_abandoned_before_trigger(): close more than TOL below the lowest low before trigger → abandoned_at set, as_of after it hides the row
def test_detect_with_gaps_uses_bar_positions(): remove two 5m bars between the lows; MIN_SEP still counted in bars; pattern still found
def test_forming_at_close_is_kept(): L2 confirmed in the day's last 3 bars → pattern present, triggered_at None, as_of(15:14) state forming
def test_as_of_state_transitions(): for a triggered-then-failed pattern: as_of(before formed_at) == []; forming at formed_at; triggered at triggered_at; failed at failed_at
def test_as_of_never_uses_future(): for 5 random seeded days: for every minute m at 5-min steps, rows from as_of(detect_day(full), m) == rows from as_of(detect_day(full cut at m), m) (compare kind, points, neckline, state)
def test_score_without_oi(): oi column all zero → checks[1] is False, score <= 4
def test_score_checks_order_and_count(): a triggered pattern with everything agreeing scores 5 and checks == [True]*6
def test_detector_hash_changes_with_params(): detector_hash() != detector_hash({**DEFAULTS, "tol": 0.005})
def test_perf_30_symbol_days(): 30 synthetic days through detect_day in < 0.3 s total
